- [ ] 공개 전 별도 검수자 승인 흐름과 `reviewed` 전환 규칙을 자동 검증한다.

- [ ] 카드 기억 상태와 개념 숙달 증거를 별도 상태로 계산

## 구현 경계

- 이 도메인 코어는 기존 영어 학습 서비스의 DB 스키마나 사용자 모델을 참조하지 않는다.
- 콘텐츠는 비공식 복원 문제를 수집하지 않고 공식 범위에 근거해 독자 작성한다.
- AI는 채점의 권위자가 아니며 검수된 규칙이 정오 판정을 담당한다.
- 첫 제출 이후의 수정은 학습에는 사용하되 독립 회상 성공으로 덮어쓰지 않는다.
- 오답 또는 도움 사용 답안은 `Hard/Good/Easy`로 기록할 수 없다.

## 다음 작업 우선순위

1. 콘텐츠 계약을 JSON Schema로 고정하고 `reviewed` 전환에 별도 검수자 승인을 강제한다.
2. 별도 PWA 앱에서 게스트 학습 이벤트를 로컬에 저장하고 재생할 수 있게 한다.
3. FSRS 구현체를 연결해 동일 이벤트 재전송의 멱등성과 기억 상태 재계산 계약을 통합 테스트한다.

# BBC 사용 조건 요약 (개인정보 제거본)

이 문서는 프로젝트에 제공된 승인 이메일에서 개인 정보와 메일 헤더를 제거하고 제품이 준수해야 할 조건만 요약한 운영 기준이다. 원본 승인을 독립적으로 보증하거나 법률 자문을 제공하지 않는다. 원본 이메일은 저장소 밖의 접근 제한 저장소에 보관한다.

- 비상업 교육 목적으로만 운영한다.
- BBC 헤드라인과 기사당 최대 200자의 발췌만 사용한다.
- 각 콘텐츠에서 BBC 표시와 원문 링크를 제공한다.
- BBC 공식·제휴 서비스가 아님을 명확히 표시한다.
- 광고, 후원, 구독, 유료 기능 등 수익화를 하지 않는다.
- 수익화 검토 전 BBC 콘텐츠 공급을 중단하고 별도 승인을 받는다.
- 승인 철회나 권리 이슈가 발생하면 공급원 kill switch와 개별 철회 기능으로 공개를 중단한다.
- 기사 본문 전체를 수집·저장·번역·검수 모델에 전달하지 않는다.
